# 🎬 Bot Muzic Video

بات تلگرامی که اسم آهنگ (یا خود فایل صوتی) رو می‌گیره، موزیک ویدیوش رو از یوتیوب پیدا می‌کنه و **هم لینک** و **هم خود ویدیو** رو برات می‌فرسته.

اگه موزیک ویدیوی رسمی پیدا نشه، ۱۰ تا از ویدیوهای فن‌مید/مرتبط رو با تامبنیل نشون می‌ده و تو انتخاب می‌کنی کدوم برات دانلود و ارسال بشه.

## ⚙️ راه‌اندازی

```bash
npm install
```

1. از [@BotFather](https://t.me/BotFather) یه بات بساز و توکنش رو بگیر.
2. فایل `.env.example` رو به `.env` کپی کن و `BOT_TOKEN` رو پر کن:

```
BOT_TOKEN=123456789:AA...your_token...
```

3. اجرا:

```bash
npm start
```

## 🌐 پروکسی (برای کاربران ایران)

اگه سرور/سیستمت به یوتیوب و تلگرام دسترسی مستقیم نداره، توی `.env` این خط رو فعال کن:

```
HTTPS_PROXY=http://127.0.0.1:10809
```

پروکسی به‌صورت خودکار برای جستجوی یوتیوب، دانلود ویدیو، دانلود تامبنیل‌ها و ارتباط با API تلگرام اعمال می‌شه. اگه ست نشه، اتصال مستقیم انجام می‌شه.

## 📱 نحوه استفاده

- **اسم آهنگ رو تایپ کن** → مثلاً: `Shape of You Ed Sheeran`
- **فایل صوتی بفرست** → اسم آهنگ از تگ‌های ID3 (`title` و `performer`) یا اسم فایل تشخیص داده می‌شه.
- اگه موزیک ویدیوی رسمی پیدا بشه → لینک + فایل ویدیو (۳۶۰p، زیر ۵۰ مگابایت) مستقیم ارسال می‌شه.
- اگه پیدا نشه → ۱۰ تامبنیل از نتایج مرتبط با دکمه‌های شماره‌دار میاد؛ شماره رو بزن تا همون ویدیو برات ارسال بشه.
- لینک یوتیوب هم بفرستی، همون ویدیو برات دانلود و ارسال می‌شه.

## 📁 ساختار

```
src/
├── index.js                  # نقطه ورود و راه‌اندازی بات (grammY)
├── config.js                 # تنظیمات مشترک (مسیر temp، سقف حجم و ...)
├── utils.js                  # ابزارهای کمکی
├── keyboards.js              # کیبورد اینلاین انتخاب از ۱۰ گزینه
├── handlers/song.js          # فلوی اصلی: جستجو، آلبوم تامبنیل، ارسال
├── services/
│   ├── youtube.js            # جستجوی یوتیوب بدون کلید API (yt-search)
│   ├── download.js           # دانلود با yt-dlp + ادغام صدا/تصویر با ffmpeg-static
│   ├── thumbnail.js          # دانلود تامبنیل‌ها
│   ├── selection-store.js    # نگهداری موقت لیست انتخاب کاربر
│   └── proxy.js              # اعمال پروکسی (اختیاری)
└── scripts/
    ├── test-services.js      # تست جستجو/تامبنیل/getInfo بدون تلگرام
    ├── dl-test.mjs           # تست دانلود کامل یک ویدیو
    └── lore-test.mjs         # اعتبارسنجی پیام‌های لور (۲۰۰ نمونه: بدون تکرار، تگ HTML متوازن)
```

## 📝 نکات فنی

- **سقف Bot API تلگرام:** ۵۰ مگابایت برای ارسال فایل → ویدیو با کیفیت حداکثر ۳۶۰p (بهترین ویدیو + بهترین صدا، ادغام‌شده با ffmpeg داخلی) ارسال می‌شه. ویدیوهای بلندتر از ۱۵ دقیقه فقط لینک می‌گیرن.
- **پیام‌های لور «نسرین/jonquil»:** استخر ~۸۰ پیامه‌ی کوتاه در `src/services/lore.js` (فارسی + چند انگلیسی)، با فرمت HTML تلگرام (`<i>`، `<blockquote>`، `<tg-spoiler>`، `<blockquote expandable>`) و چرخش بدون تکرار (deck شافل). ادیت‌های پیام با حداقل ۵ ثانیه فاصله throttle می‌شن (محدودیت rate تلگرام).
- **yt-dlp + ffmpeg-static:** هر دو باینری به‌صورت خودکار با `npm install` دانلود می‌شن و نیازی به نصب سراسری ندارن. برای به‌روزرسانی yt-dlp (اگه یوتیوب تغییرش داد): `npm run update-ytdlp`.
- نیازی به کلید YouTube Data API نیست.
